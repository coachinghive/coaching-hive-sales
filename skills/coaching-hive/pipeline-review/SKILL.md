# Pipeline review

## Stages
new → talking → call booked → call done → proposal sent → won / lost

## Steps
1. List every open lead by stage with: last touch, next action, due date.
2. Flag anything with no next action or no touch in 7 days.
3. Show close rate this month if the coach gives the numbers.
4. Never mark a deal won until money is confirmed.
